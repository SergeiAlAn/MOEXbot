Ты — опытный Python-разработчик, специализирующийся на Telegram-ботах, API интеграциях и автоматизации финансовых сервисов.

Создай полноценный Python-проект Telegram-бота, который отслеживает индексы Московской биржи:
- MOEX (Индекс МосБиржи)
- MOEX2 (Индекс МосБиржи полной доходности)

Цель бота:
Регулярно получать котировки индексов и отправлять мне уведомления в Telegram по заданному расписанию.

## Основные требования

### 1. Источник данных

Используй официальный API Московской биржи ISS MOEX.

Бот должен получать:
- текущее значение индекса MOEX
- текущее значение индекса MOEX2
- изменение в процентах
- изменение в пунктах
- значения на начало торгового дня

Не используй сторонние сайты-агрегаторы котировок.

Предусмотри отдельный модуль для работы с API MOEX:
например:
moex_api.py

Все запросы к API должны быть изолированы в этом модуле.

# 4. Логика работы бота

## Проверка торгового дня

Каждый день в 10:00 бот должен проверить:

Есть ли сегодня торги на Московской бирже.

Если торгов нет:

Отправить:

"Сегодня торгов нет"

После этого:
- больше сообщений сегодня не отправлять
- ждать следующего торгового дня

---

# 5. Первое сообщение в 10:00

В 10:00 бот отправляет сообщение:

"Утренняя сессия MOEX2"

Содержание:

MOEX2:
- текущее значение после утренней сессии
- изменение с начала утренней сессии
- изменение в процентах


Пример:

MOEX2:
3400.25 пунктов
+12.5 (+0.37%)
с начала утренней сессии

# 6. Регулярные уведомления

13:00
14:00

Изменение рассчитывать относительно значения индекса на начало торгового дня.
